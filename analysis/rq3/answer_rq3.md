# RQ3：访谈信息的下游工程价值

RQ3 的结果以一张双面板图和一张四行表回答：访谈获得的信息能支持多少功能与边界实现，以及这些需求在重复实现中能否获得一致判定。正式数据来自已导入的 `reviewed_judgments.json`，主分析范围为需要评价的 FR、BR、EX。

## 证据角色

主图 `rq3_implementation_outcomes` 分别展示功能需求与业务规则/异常边界。柱高为至少两次可判定观测的需求数，分段表示一致满足、一致部分满足、一致不满足与判定变化。柱顶标注一致数/重复观测数。

表 `table_rq3_summary` 汇总五个 Case 的行为需求，报告 N、O、R、S（A）与 R5/S5/P5。A 为汇总 S/R；R5 表示五次完整观测，S5 表示五次判定一致，P5 表示五次均满足。统计采用汇总计数、Case 内配对描述与五次完整观测分析。

## Results 的三个段落

**总体行为需求。** ElicitMind 的 443 条行为需求中，213 条至少一次获得可判定观测，143 条获得重复观测，101 条在已观测运行中具有一致判定，条件一致率为 70.6%。可观测需求数与判定一致需求数均高于三个基线。在总体行为需求范围内，相对 LLMREI-long、Hashimoto 和 SparkMe，可观测需求数分别在 5、4、3 个 Case 上更高，判定一致需求数分别在 5、4、2 个 Case 上更高。

**功能与边界。** 判定一致需求包含 81 条功能需求和 20 条业务规则与异常边界需求。在业务规则与异常边界范围内，45 条需求至少一次获得可判定观测，26 条获得重复观测；可观测需求数与判定一致需求数均高于三个基线。这些需求涵盖条件、约束和异常处理，扩展了核心功能之外的可验证范围。

**五次完整观测。** ElicitMind 有 48 条行为需求在五次独立实现中均获得可判定观测，其中 28 条判定完全一致，13 条五次均满足。这三项数量均高于三个基线。

## Answer to RQ3

ElicitMind 的访谈结果支持更多功能、业务规则与异常边界需求获得可判定观测，并形成更多跨运行判定一致的需求；五次独立实现中均满足的需求数也高于三个基线。

RQ1 展示访谈获得的信息，RQ2 展示访谈过程质量，RQ3 通过需求关联的执行评价展示这些信息的下游支持价值。正文按“整体规模—功能与边界—五次完整观测”展开，采用一图一表，Case 配对结果用一句文字概括。
