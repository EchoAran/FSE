# 阶段五：行为校验与实施收尾

## 目标

确认当前实现仍然是 LLMREI-long，而不是被外围工程逻辑改变的方法。

## 校验重点

人工检查若干访谈：

- 是否围绕软件需求进行询问；
- 是否能够利用前文回答继续追问；
- 是否存在明显重复；
- 是否出现 Prompt 脱轨；
- 是否由单 LLM 自主决定下一问题；
- 是否没有显式 Topic/Slot/Planner 介入。

## 技术检查

- 多 Case 连续执行；
- API failure 有明确日志；
- transcript 可重放。

## 实施说明（可选）

如有必要，可在全部实施结束后于本项目根目录统一补充一份 `IMPLEMENTATION_NOTES.md`，只说明实际完成内容、必要偏差与已知限制。

不在代码中增加版本号、哈希、配置快照或专门的追溯元数据。

## 验收标准

- 最小方法闭环稳定；
- 没有额外访谈决策模块；
- 所有改造均限于输入、接口和工程封装；
- README 能指导从空环境完成一次运行。

## 阶段产物

- 最终运行说明；
- 可选的 `IMPLEMENTATION_NOTES.md`。
