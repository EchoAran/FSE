# 阶段四：接口与日志规范化

## 目标

将 LLMREI-long 从一次性脚本整理为可复用的访谈组件。

## 推荐接口

```python
class LLMREIInterviewer:
    def initialize(self, case):
        ...
    def get_first_question(self):
        ...
    def step(self, interviewee_answer):
        ...
    def export_transcript(self):
        ...
```

## 日志

每轮记录：

- turn index；
- interviewer utterance；
- interviewee utterance；
- 运行错误（如有）。

使用一种结构化格式保存 transcript。

## 配置

把以下内容放入 YAML：

```yaml
model:
temperature:
max_tokens:
max_turns:
prompt_path:
```

Prompt 文件本身不写入 YAML。

这些参数只作为当前运行输入，不复制到 transcript，也不生成配置快照。

## 验收标准

- 调用方不需要了解 LLMREI 内部 Prompt；
- 同一接口可以连续执行多轮；
- transcript 可以独立于运行器读取；
- 运行过程中没有隐式全局变量。
