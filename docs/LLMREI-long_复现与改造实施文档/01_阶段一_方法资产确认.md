# 阶段一：方法资产确认

## 目标

确定 LLMREI-long 复现真正需要的公开资产。

## 需要做什么

1. 获取论文 PDF。
2. 从官方 Zenodo 下载 `long_prompt.txt`。
3. 可选保留 `short_prompt.txt`，仅用于对照。
4. 阅读论文中与以下内容相关的部分：
   - long/short prompting 设计；
   - interviewer 的输入；
   - conversation history 的使用；
   - 模型调用方式；
   - 访谈整体运行逻辑。

## 不需要获取

- 原论文访谈数据；
- 人工标注数据；
- RQ 数据文件；
- 评价 notebook；
- 统计图表代码。

这些内容不会影响方法本身的运行。

## 推荐目录

```text
llmrei_long/
├── vendor/
│   ├── paper.pdf
│   └── long_prompt.txt
└── ...
```

## 验收标准

- `long_prompt.txt` 来自官方 Zenodo；
- 已明确 LLMREI-long 的最小运行输入；
- 没有把原论文实验数据作为运行依赖；
- `vendor/` 文件保持只读，不直接修改。

## 阶段产物

- `vendor/`
