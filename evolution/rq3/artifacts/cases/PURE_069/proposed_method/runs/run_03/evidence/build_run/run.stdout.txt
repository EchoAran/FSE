usage: pdfsplitmerge [-h] {split,merge,extract,interleave} ...

Local PDF split and merge tool

positional arguments:
  {split,merge,extract,interleave}
    split               split a PDF into page files
    merge               merge PDFs or selected page ranges
    extract             extract pages from a PDF
    interleave          alternate pages from multiple PDFs

options:
  -h, --help            show this help message and exit
