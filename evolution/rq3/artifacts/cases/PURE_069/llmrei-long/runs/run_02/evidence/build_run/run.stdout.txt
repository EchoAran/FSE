usage: pdf-tool [-h]
                {split,extract,merge,rotate,reorder,alternate,save-setup,run-setup}
                ...

PDF split and merge utility

positional arguments:
  {split,extract,merge,rotate,reorder,alternate,save-setup,run-setup}
    split               Split each page into a separate file
    extract             Extract selected pages
    merge               Merge PDF files
    rotate              Rotate pages
    reorder             Reorder pages
    alternate           Alternate pages from input files
    save-setup          Save reusable setup
    run-setup           Run reusable setup

options:
  -h, --help            show this help message and exit
